  □ All Yes/No fields → Mark "No" (underline with filled rectangle)
  □ AM/PM             → Underline the correct one
  □ Moving vehicle    → Occupants = 1
  □ Parked vehicle    → Occupants = 0
  □ No mobile number  → Do NOT fill mobile in insured details section
  □ Driver details    → Extract from DL document only
  □ Policy No         → Extract from insurance document (do not ask user)
  □ MUST use reportlab overlay method (form_filler.py) — annotations do NOT print
  □ PRINT ALIGNMENT   → Output is always physically printed; all text must fall within field boundaries,
                         never overflow into adjacent fields or form lines, and never get clipped at page edges

PDF FILLING METHOD:
  Script   : form_filler.py (reportlab overlay — merged into original PDF)
  Approach : Coordinates are form-specific. For each new insurer's blank form:
             1. Run PyMuPDF text extraction against the blank PDF to get label positions
             2. Calculate field value positions relative to each label's end position
             3. Add a new coordinate map in form_filler.py (backend) and claim_filler_v2.html (frontend)
             4. Upload the new blank form PDF alongside the app
  PDF Size : Standard A4 = 595.56 x 842.04 pts (verify per form — some may differ)
  Note     : Each insurer's form has unique coordinates — never reuse coordinates across forms
